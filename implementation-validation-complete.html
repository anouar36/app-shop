🚀 Quick Start Instructions

1. Start Laravel Backend

PowerShell: .\start-backend.ps1
Or manually: cd shop-backend && php artisan serve

2. Test Guest Orders (No Authentication)

POST http://localhost:8000/api/orders
(No Authorization header needed)

3. Test Authenticated Orders

POST http://localhost:8000/api/orders
Authorization: Bearer {token}

📤 API Endpoints Summary

Order Creation (Public - No Auth Required)

POST /api/orders
Headers: Content-Type: application/json
Optional: Authorization: Bearer {token}

Request Body:

{ "products_id": 1, "client_name": "Customer", "client_lastname": "Name", "email": "customer@email.com", "phone": "+1234567890", "method_payment": "Cash on Delivery", "payment_method": "cod", "date_arrival": "2025-07-15" }

Response (Guest):

{ "success": true, "message": "Order created successfully", "data": { "order_id": 123, "order_number": "#ORD-0123", "status": "new", "payment_method": "cod", "payment_status": "pending", "customer_type": "guest", "customer_id": null, "total": "$89.99" } }

Response (Authenticated):

{ "success": true, "message": "Order created successfully", "data": { "order_id": 124, "order_number": "#ORD-0124", "status": "new", "payment_method": "cod", "payment_status": "pending", "customer_type": "authenticated", "customer_id": 5, "total": "$89.99" } }
