🔧 Gmail App Password Setup

⚠️ Important: You need to create a Gmail App Password to send emails.
DO NOT use your regular Gmail password - it won't work!

Step 1: Enable 2-Factor Authentication

Go to Google Account Security and enable 2FA if not already enabled.

Step 2: Generate App Password

Create an App Password specifically for this application.

📝 Steps:
1. Click "App passwords" in Google Security
2. Select app: Mail
3. Select device: Other → Enter: "Ayoube Shop"
4. Click Generate
5. Copy the 16-character password (like: abcd efgh ijkl mnop)

Step 3: Update .env File

Edit this file: c:\xampp\htdocs\shop\shop-backend\.env

Find this line:
MAIL_PASSWORD=your_gmail_app_password_here

Replace with your App Password:
MAIL_PASSWORD=abcd efgh ijkl mnop

Step 4: Clear Laravel Cache

cd c:\xampp\htdocs\shop\shop-backend
php artisan config:clear

Step 5: Test Email

🔍 Troubleshooting

If emails don't arrive:
  • ✅ Check Spam/Junk folder in Gmail
  • ✅ Verify App Password has no spaces in .env file
  • ✅ Make sure Laravel cache is cleared
  • ✅ Check Laravel logs for errors
Get-Content "c:\xampp\htdocs\shop\shop-backend\storage\logs\laravel.log" -Tail 20
