🔧 Fix Email Notifications - Gmail App Password Setup

❌ Problem Identified

Issue: You're not receiving email notifications when clients place orders.

Cause: Gmail App Password is not configured in your .env file.

Current Setting: MAIL_PASSWORD=your_real_gmail_app_password_here

🔑 Step 1: Generate Gmail App Password

Follow these steps to create a Gmail App Password:

  1. Go to Google Account Security:
  2. Enable 2-Step Verification:
    If not already enabled, turn on 2-Step Verification first.
  3. Create App Password:
    • Look for "App passwords" section
    • Click "App passwords"
    • Select app: "Mail"
    • Select device: "Windows Computer"
    • Click "Generate"
  4. Copy the 16-character password:
    Example: abcd efgh ijkl mnop

    ⚠️ Save this password - Google will only show it once!

⚙️ Step 2: Update .env File

Location: c:\xampp\htdocs\shop\shop-backend\.env

Find this line:

MAIL_PASSWORD=your_real_gmail_app_password_here

Replace with your App Password (remove spaces):

MAIL_PASSWORD=abcdefghijklmnop

🔄 Step 3: Restart Laravel Server

After updating the .env file, restart your Laravel server:

cd c:\xampp\htdocs\shop\shop-backend php artisan serve --host=127.0.0.1 --port=8000

🧪 Step 4: Test Email Notifications

Test if emails are now working:

📧 Step 5: Verify Gmail Settings

Current Email Configuration:

MAIL_MAILER=smtp MAIL_HOST=smtp.gmail.com MAIL_PORT=587 MAIL_USERNAME=anouarechcharai@gmail.com MAIL_PASSWORD=[YOUR_APP_PASSWORD_HERE] MAIL_ENCRYPTION=tls MAIL_FROM_ADDRESS=anouarechcharai@gmail.com MAIL_ADMIN_EMAIL=anouarechcharai@gmail.com

✅ What to Expect After Fix

Once the Gmail App Password is configured, you will receive:

  • 📧 Professional email notifications for every new order
  • 🛒 Order details including customer info and products
  • ⚡ Immediate delivery to anouarechcharai@gmail.com
  • 🔔 Dashboard notifications in the admin panel
  • 📱 Mobile notifications if Gmail is on your phone

🆘 Troubleshooting

If emails still don't work after setup:

  • ✅ Check your spam/junk folder
  • ✅ Verify the App Password has no spaces
  • ✅ Ensure 2-Step Verification is enabled
  • ✅ Check Laravel logs: storage/logs/laravel.log
  • ✅ Test with a simple email first
