🛒 Order API Email Test - Postman Alternative

📋 What This Does

This interface simulates Postman to test the order API. When you create an order:

  • ✅ Order is saved to database
  • 📧 Email automatically sent to admin: anouarechcharai@gmail.com
  • 📨 Email contains all customer and order details
  • 🎯 Professional HTML email template

🔗 API Endpoint Information

POST http://localhost:8000/api/orders Content-Type: application/json Accept: application/json

📝 Create Order & Send Email

📬 Postman Instructions

1. Setup Postman Request:

Method: POST URL: http://localhost:8000/api/orders Headers: Content-Type: application/json Accept: application/json

2. Request Body (JSON):

{ "client_name": "Ahmed", "client_lastname": "Benali", "email": "ahmed.benali@gmail.com", "phone": "+212661234567", "products_id": 1, "method_payment": "cod", "payment_method": "cod", "address": "123 Rue Hassan II, Casablanca, Morocco" }
